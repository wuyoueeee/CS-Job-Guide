# AI 研发面试问题合集（牛客近一年）

这份合集整理自牛客网近一年（2025 年秋招季到 2026 年 9 月）的 15 篇 AI 研发方向公开面经，覆盖大模型算法、多模态、推荐加大模型、AI Infra、模型部署与 MLOps 五个方向。问题按模块聚合去重，同一道题被多家公司问到的会并列标注来源。

它和[大模型与 AI 面试高频题](./大模型与AI面试高频题.md)分工不同：那篇讲"面试官想考什么、怎么答"，这篇讲"实际考了什么、哪些题反复出现"。准备时先拿这份合集扫盲，再对照高频题补答法。

来源标注用方括号简写，完整链接见文末来源清单。统计口径说明：文中"N 篇提到"只统计本合集收录的 15 篇，不代表全市场频率。

## 一、模型结构与基础原理

这一模块是筛掉"背过结构图但没想过为什么"的人的地方，几乎每篇面经都有 2 到 4 题。

### Transformer 与注意力

1. Self-Attention 的计算流程，Q/K/V 分别是什么，Attention Score 为什么除以根号 d_k，不缩放会怎么样【字节多模态、聚合帖-快手2025、百度】
2. 多头注意力为什么比单头好，多头机制的核心优势是什么【字节多模态、快手应用、聚合帖-快手2025、百度、腾讯多模态】
3. Decoder 的因果注意力，QKV 分别来自哪，为什么要用自回归因果掩码【字节多模态、聚合帖-快手2025】
4. MHA、MQA、GQA 三种注意力机制的区别，推理速度、显存占用、KV Cache 占用比例的差异【百度】
5. DeepSeek 的 MLA 讲一下，decode 阶段的计算访存比怎么分析，和 seqlen、batch size 是否相关【聚合帖-快手2025、AI Infra 面经】
6. 为什么现在 Decoder-only 成为主流架构，BERT 和 GPT 的区别，大模型时代小模型还有什么用【字节豆包、聚合帖-快手2025】
7. Transformer 怎么做加速训练，训练和推理有什么区别【字节多模态】
8. Decoder 文本生成有哪几种方法，大模型预测 token 的损失怎么算，常见损失函数有哪些【字节多模态、聚合帖-快手2025】
9. Transformer 的核心优势是什么，为什么适合作为 AI 基础引擎【腾讯多模态】

### 位置编码与归一化

1. RoPE 的原理和优点，目前常用的位置编码还有哪些【字节豆包、聚合帖-快手2025】
2. 为什么用 RMSNorm，和 LayerNorm 有什么差异，什么场景用哪个【快手应用、字节推荐】

### 模型结构细节

1. Qwen2 的模型结构，相比 Qwen1 做了哪些改进；Qwen2.5-VL 的架构拆解【字节豆包、腾讯多模态】
2. MoE 加在什么地方，从训练和推理两个角度分析 MoE 的好处，优缺点分别是什么【聚合帖-快手2025、字节推荐】
3. 大模型训练为什么不用 SFT（三面连环追问：SFT 之后为什么还要 RLHF）【字节多模态、字节豆包】
4. 大模型的灾难性遗忘问题怎么解决【字节豆包】
5. 模型权重初始化的通用方案，Kaiming 初始化原理【腾讯多模态】

## 二、预训练与训练框架

这一模块考的是"你真跑过训练还是只跑过开源脚本"。

1. DeepSpeed 和 Megatron 分别介绍一下，分布式训练的常见策略（DDP、Tensor 并行、Pipeline 并行、ZeRO-1/2/3）【字节多模态、AI Infra 汇总】
2. ZeRO-Offload 加 Sequence Parallel 加 FlashAttention 在万卡训练里怎么组合，3D 并行的通信开销怎么算【AI Infra 面经、美团北斗】
3. 混合精度训练，BF16 和 FP8 的区别，大模型 OOM、低 MFU、hang 怎么诊断【美团北斗】
4. 微调的数据配比是怎样的，中文领域做 Instruction Tuning 要注意哪些数据问题【字节豆包、快手应用】
5. SFT 数据质量怎么把控：来源筛选、去重去偏、标注规范、交叉校验、评估指标，有没有做长尾任务上采样【MiniMax】
6. 模型蒸馏的两种方式（硬标签、软标签），蒸馏和量化的区别，知识蒸馏放在预训练阶段是否合适【蚂蚁、AI Infra 汇总、AI Infra 面经】
7. 预训练阶段用了多大学习率，warmup 步数怎么设，有没有做上下文扩展、用的什么方案【MiniMax】
8. 如何搭建训练数据构造 Pipeline（一面场景题，讲不清数据来源、清洗、配比、质检就容易挂）【字节算法】

## 三、微调与 PEFT

LoRA 是这一模块的绝对核心，本合集 15 篇里有 4 篇问到，且都问到实现细节而不是概念。

1. LoRA 的底层原理，初始化怎么做的，矩阵 A 和 B 分别怎么初始化，B 为什么初始化为 0，A 可以吗，什么是矩阵的秩【字节多模态、聚合帖-快手2025、腾讯多模态】
2. LoRA 用的秩是多少，为什么不选其他数；用 3x3 矩阵时 rank 怎么选【字节多模态、腾讯多模态】
3. LoRA 和 Prompt Tuning 的区别，分别适合什么场景；Adapter 的具体实现方式；PEFT 了解哪些【快手应用、腾讯多模态、字节多模态】
4. LoRA 到底省了多少参数，加在 Transformer 哪些模块，为什么加在这些模块【腾讯多模态、商汤（见[面经库](../面经/商汤大模型算法应用实习面经（已offer）.md)）】
5. 模型微调时遇到过过拟合吗，怎么处理的【快手应用】

## 四、后训练与强化学习

2026 年的明显变化：PPO/DPO 已成常规题，GRPO、DAPO 这类新方法和训练细节追问大幅变多。

### SFT 与 RL 的关系

### PPO、DPO 与新方法

2. PPO 训练流程，Actor、Critic、Reward Model、Reference Model 分别做什么，为什么要 KL 约束，KL 散度系数怎么调【字节Seed、蚂蚁、MiniMax、商汤】
3. Critic Model 的作用是什么，有了 Reward Model 为什么还需要 Critic【蚂蚁】
4. GRPO 讲一下，GRPO 里 KL 散度和之前的方法有什么区别，DAPO 为什么舍弃 KL 散度，GSPO 的主要改进【字节算法、蚂蚁、聚合帖-美图】
5. 最近的 RL 方法过一遍：GRPO、DAPO、GSPO 各自解决什么问题【蚂蚁】
6. 过程监督的信号具体怎么设计，还能应用在哪些地方；Reward Model 怎么设计，对比数据怎么构造，有没有考虑排序一致性【聚合帖-美图、MiniMax、字节算法】
7. DeepSeek-R1 里面的奖励设计（奖励函数和奖励模型），第一阶段、第二阶段怎么开展【字节算法】
8. On-policy 和 Off-policy 有什么区别【聚合帖-快手2025】

### 训练细节与稳定性

1. 强化学习数据集的构建方法，RL 数据怎么配比【聚合帖-美图、字节算法】
2. 如何保证 RL 的训练效率，平衡效率和稳定；GRPO 训练中出现全 0 或全 1 的奖励怎么解决【聚合帖-美图】
3. 发现策略崩溃（大量重复或无意义输出）怎么处理：检查奖励模型是否被攻击、增大 KL 惩罚、降学习率、回滚检查点【MiniMax】
4. 熵崩溃是什么概念，怎么观察到【字节Seed】
5. 混合推理怎么做（GPT-5 路线），增强推理时怎么保证通用数据不遗忘【聚合帖-美图】
6. RLHF 和 RLAIF 的差异，RLAIF 在企业级场景的可行性，怎么防止反馈循环里的质量劣化【MiniMax】
7. Verl 框架的训练流程，rollout batch size、global batch size、micro batch size per device for update、rollout n 这些参数的关系，怎么影响每张卡上的样本数【蚂蚁】

## 五、推理与部署

这是 AI Infra 和部署岗的主战场。一篇基于 355 条面试记录的统计里，「AI 模型部署」出现 8 次居首，「模型量化」6 次，「vLLM」和「模型漂移」各 4 次【MLOps 洞察】。

### KV Cache 与推理引擎

1. KV Cache 怎么起作用，为什么对长上下文推理很关键，GQA 的思想是什么【快手应用、字节豆包】
2. PagedAttention 的工作原理，能否降低显存占用、底层原因；vLLM 的整体架构，请求在其内部怎么流转【百度、AI Infra 汇总、MLOps 洞察】

4. FSDP 和 DeepSpeed 怎么实现显存优化，GPU 显存怎么优化（量化、KV cache 分页、梯度检查点、混合精度、ZeRO、offload）【MLOps 洞察、AI Infra 汇总】
5. Mooncake 以 KV-Cache 为中心的 PD 分离设计思路【AI Infra 面经】
6. FlashAttention 的思想和做法，v2 为什么外层对 Q 循环，Flash Decoding 的 combine kernel 耗时占比大概多少【字节豆包、AI Infra 面经】

### 量化与压缩

1. 量化的基本概念和方法（PTQ、QAT），INT8/INT4/FP8 的原理，量化后的坑怎么规避（校准集代表性、关键层保精度）【MLOps 洞察、AI Infra 汇总】

2. 怎么判断推理时显卡是算力不足还是显存不足；估算部署 235B、稀疏率千分之三的 MoE 需要多少算力【MLOps 洞察】

5. 推理服务的限流和兜底（令牌桶、优先级队列、降级到小模型或规则回复）【AI Infra 汇总】

1. 模型漂移：离线指标更优的模型上线后效果反而不如旧版，怎么分析；线上 CTR 远低于离线 AUC 从哪排查【MLOps 洞察】

## 十、场景与开放题

这类题没有标准答案，考的是链路完整性：能把问题拆成阶段、每个阶段有方案、方案有取舍。

1. 如何搭建训练数据构造 Pipeline（数据来源、清洗、配比、质检、迭代闭环）【字节算法】
2. 电商场景用大模型解决问题，Prompt 怎么设计，怎么处理模型输出，怎么过滤错误格式的输出【字节多模态】
3. 如果为一个通用助手模型做后训练，数据配比和训练阶段怎么设计【MiniMax】
4. 后训练项目里效果提升最大的一个改动是什么，怎么确定是它起的作用（消融实验设计）【MiniMax】
5. 画出训练 pipeline 的整体架构，包括数据流、模型更新流程、评测环节的插入位置【MiniMax】
6. 你觉得当前大模型后训练方向最大的技术瓶颈是什么，有足够资源会优先解决哪个【MiniMax】
7. 用过豆包吗，觉得目前还存在什么问题（开放题，考产品sense）【字节豆包】
8. Oncall 场景：很多告警不可能全处理，怎么设计处理机制【聚合帖-腾讯后台】

## 十二、用法建议

1. **先扫模块一和模块九**。基础题和手撕题是入场券，这两块不过，项目讲得再好也走不到后面轮次。
2. **RL 细节是 2026 年最大的增量**。只背 PPO/DPO 概念已经不够，GRPO、DAPO、KL 系数、奖励崩塌处理这些要能讲到数值层面。手里没有真跑过 RL 的，按[大模型与 AI 面试高频题](./大模型与AI面试高频题.md)的 RL 章节搭一个最小训练实验，把超参和日志记下来。
3. **按目标公司侧重**。面大模型公司（MiniMax、字节 Seed、蚂蚁）重点准备模块二到四；面 Infra 岗重点准备模块五；面多模态岗把模块六当论文复现准备，不要只读摘要。
4. **场景题用同一套结构答**：先问清场景和约束，再给分阶段方案，最后讲降级和取舍。模块十的题都可以这么拆。
5. **每道题标注自己的状态**。建议复制这份合集到自己的笔记里，逐题标"能讲 3 分钟/讲过但接不住追问/没准备过"，优先补第二类。
