### 适合谁

| 适合谁 | 你能怎么用 |
| --- | --- |
| 计算机相关专业在校生 | 按校招时间线准备简历、项目、笔试和面试 |
| 准备后端、AI 应用研发、测试开发、前端等技术岗 | 从岗位地图、项目专题和面试题里选主线 |
| 简历投递反馈弱、项目讲不深的人 | 用证据库、项目深挖和复盘模板补强表达 |
| 想投银行科技、国企科技岗 | 对照稳定性、笔试、面试和签约风险准备 |
| 已拿 offer、正在纠结 | 用 offer 决策表比较成长、薪资、城市和风险 |
| 想把 AI 用进求职各环节 | 从七环节主线入手，每步都有工作流、提示词和校验点 |

不适合想找「包过」「保 offer」捷径的人，也不适合只想背标准答案、不愿复盘项目的人。
