# 传统后端项目：Java 后端方向的底子

这个目录下的五篇，服务的是**Java 后端、中间件、金融科技岗**的求职。它们和上面的大模型项目不是竞争关系，是两条不同的路。

**该走这条路，如果**：你目标岗位的 JD 里出现的是 Spring、MySQL、Redis、消息队列、高并发、分布式，而不是 RAG、Agent、评测。

**该走大模型那条路，如果**：JD 里出现的是大模型应用、RAG、Agent、Prompt、评测、向量库。

两条路都有前途，选错才麻烦。判断方法很简单：去找 3 份你真正想投的 JD，看关键词分布，别看哪个方向听起来热。

## 五篇拆解

| 项目 | 讲什么 | 适合谁 |
| --- | --- | --- |
| [秒杀系统](./秒杀系统项目拆解.md) | 流量漏斗、库存一致性、异步削峰、超时补偿 | 想练高并发 |
| [短链系统](./短链系统项目拆解.md) | 编码算法、多级缓存、穿透防护、统计聚合 | 想练系统设计入门 |
| [IM 系统](./IM系统项目拆解.md) | 长连接管理、消息序号、投递语义、离线同步 | 想体现分布式理解 |
| [API 网关](./API网关项目拆解.md) | 责任链、限流算法边界、熔断、动态路由 | 想体现工程抽象 |
| [权限系统](./权限系统项目拆解.md) | RBAC、四层权限、数据权限、审计 | 金融国企岗、通用基础能力 |

五篇都按同一个套路写：**先算账（容量和延迟预算）、再设计（每个决策都给替代方案）、再验证（压测、对账、故障注入）**。

每篇除数据图外还配结构示意图，两类图分工不同：

| 项目 | 数据图 | 结构示意图 |
| --- | --- | --- |
| 秒杀 | 流量漏斗、延迟预算、超卖曲线 | 削峰与兜底架构图、订单状态机 |
| 短链 | 命中率与数据库 QPS、统计写入量 | 命中率曲线（指数型） |
| IM | 连接数内存、离线消息增量 | 消息投递时序图 |
| API 网关 | 四种限流算法对比、网关开销、放行曲线 | 责任链架构图、熔断状态机 |
| 权限 | 三种鉴权成本、越权测试矩阵 | 数据权限 SQL 改写 |

15 张数据图加 5 张示意图，假设与算式都登记在 [`docs/_data/project-metrics.json`](../../_data/project-metrics.json)，由脚本生成可复现：

```bash
python tools/build_project_charts.py        # 数据图 15 张
python tools/build_project_diagrams.py      # 示意图 9 张（含大模型项目）
```
