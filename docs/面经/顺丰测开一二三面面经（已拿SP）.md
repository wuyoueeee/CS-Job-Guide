## 基本情况

- 公司/岗位：顺丰科技，测试开发工程师（秋招）
- 轮次：一面、二面、三面（HR 面）
- 结果：已拿意向书，offer 开到 SP
- 时间线：9.4 一面，9.8 二面，9.16 三面，9.20 意向书，9.25 offer 开奖

## 一面（9.4，相当于摸底）

大部分时间是自己在讲项目，加一些开放性问题的自问自答，比如对 Python 的熟悉程度。

## 二面（9.8，面试官为高级测开工程师，全程约 26 分 50 秒）

1. 自我介绍
2. 项目里最深刻的困难点及解决方法
3. 项目中的测试流程是怎么规划的
4. Python 的 GC 机制
5. Python 的反射机制
6. Python 中 `__new__` 和 `__init__` 的区别
7. MySQL 查表中的前 10 行
8. MySQL 的表连接
9. HTTP 协议的连接有了解吗，解释一下三次握手
10. Linux 命令：对指定的用户分配只读权限
11. Linux 命令：整个目录拷贝到另一个目录下，不确定后者是否已存在同名目录

反问（表现及改进点）：面试官明确说这是测开岗不是测试岗，建议补充开源框架知识；反馈 3-5 天出。

## 三面（9.16，HR 面）

HR 面被安排在最后一天，分享者心态受影响，体验一般。反问流程并提出质疑后，HR 有提示让自信一点。

## 复盘建议

- 一面像摸底，项目讲清楚就能过；二面是主力淘汰轮，Python 基础（GC、反射、`__new__`/`__init__`）加 MySQL、Linux 命令的组合很常见，建议每条命令都动手敲一遍，别只背选项。
- "测开岗不是测试岗"这句反馈值得记下：测开的考察重心在工程能力，测试流程、自动化框架、开发语言基础都要准备，只背测试理论不够。
- MySQL 前 10 行、目录拷贝这类题属于"用过就不会忘"，平时在 Linux 里做项目时刻意用命令行完成，别全点鼠标。
- 从投递到 offer 约三周，节奏很快。顺丰这轮流程推进利索，等待期间保持状态继续面别停。
