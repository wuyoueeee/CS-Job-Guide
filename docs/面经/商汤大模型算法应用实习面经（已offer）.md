## 一面（偏基础和简历深挖）

2. Self-Attention 公式，Q/K/V 分别是什么
3. PPO/RLHF 里 Actor、Critic、Reward Model、Reference Model 分别做什么，为什么要 KL 约束
4. 有没有做过分布式训练，常见模型并行方式有哪些，ZeRO-1/2/3 区别
5. RAG 原理，项目里有哪些相关经验，向量数据库、相似度计算、chunk 切片策略
6. Git、AI Coding、Python 基础
7. 基础手撕

反问得到的答复：

- 岗位实际业务偏大模型应用落地、RAG、Agent 框架和知识问答产品
- 业务为主，但鼓励研究产出
- 算力资源充足，但当前更多是 agent 和应用开发

## 二面（偏多 Agent、多模态和开放系统设计）

面试官主要针对简历里的实习工作做开放的系统架构设计：

1. 固定的"感知-推理-校验"流程和动态多 Agent 最大区别是什么
2. 如果拆成感知、推理、校验 Agent，哪些能并行，哪些要顺序，什么时候需要反向通信
3. 校验 Agent 和推理 Agent 结论冲突时怎么处理
4. 多模型如何动态路由：不同模型适合不同视频场景时，怎么根据视频特征、任务特征、成本、延迟和效果选模型
5. 所有模型超时或故障时怎么兜底，什么时候用规则引擎，什么时候转人工，服务恢复后怎么回切
6. 能不能让系统自动发现问题、尝试策略、验证效果，并自动生效和回滚
7. 开放设计题：设计智能家庭安防管家，识别入侵、火灾、老人跌倒、宠物破坏等事件，并路由到报警、通知、开灯、联系家属等流程；还要考虑视频、声音、传感器时效不同下的渐进式响应，以及用户用自然语言配置规则（比如外卖员放门口不报警）
8. 工作是否一定要涉及后训练，能不能接受 Agent 工程、Prompt、RAG、Workflow、评估体系

反问得到的答复：

- 团队主要做多 Agent 协作、多模态问答和办公场景应用（PPT 生成、文档撰写、论文写作/审核、财务报表处理）
- 前期用闭源模型做 PoC/MVP，后续可能做开源、垂类后训和性能优化

## 复盘建议

- 一面是典型的"大模型应用岗基础套餐"：LoRA、Attention、RLHF、分布式训练、RAG。这些概念在[大模型与 AI 面试高频题](../基础知识/大模型与AI面试高频题.md)里都有，但面试考的是组合追问，比如 LoRA 加在哪些模块、为什么加在这些模块。
- 二面几乎不问八股，全是开放系统设计，核心考点是 Agent 拆分后的并行/串行/冲突处理、多模型路由的取舍维度、故障兜底和回切。这类题没有标准答案，建议按"先定义场景和约束，再给架构，再讲降级"的结构回答。
- 反问环节信息量很大：岗位是应用落地而不是研究，提前问清是否接受纯工程方向（Prompt、RAG、Workflow、评估），可以避免入职后方向错配。
