## 技术一面（2025.10.28）

1. 针对简历问项目细节，比如 Agent 怎么做历史记忆
2. 推荐系统的指标：召回率、精确率、准确率的区别
3. 如果出现过拟合和梯度爆炸该如何检查
4. JDK8 有哪些新特性
5. 试图讲 ConcurrentHashMap（追问为什么要用分段锁）
6. HashMap 头插法有什么劣势（JDK7 用头插法，JDK8 改为尾插法，核心劣势是多线程环境下会导致死循环）
7. "==" 和 equals 的区别
8. String、StringBuilder、StringBuffer（追问 String 为什么不可变）
9. final 修饰的变量在 JVM 的哪一部分
10. 序列化和反序列化了解吗
11. Java 中多线程怎么实现
12. 简历中的实习工作

## 综合面试（2025.11.10）

1. 介绍实习项目，需展开具体讲一讲
2. 介绍课题（团队规模、内容、是否是毕业论文）
3. 你的特长和兴趣在哪个方向
4. 择业方向，择业时主要考虑什么核心因素
5. 你怎么看待城商行的局限性（分享者自述没答好）
6. 反问：技术栈和交付的产品

## 复盘建议

- 银行技术面的八股集中在 Java 基础（集合、String、final、序列化、多线程），难度低于互联网大厂，但要求准确。头插法死循环、final 变量存储位置这类细节题，靠[大模型与 AI 面试高频题](../基础知识/大模型与AI面试高频题.md)和 Java 基础专题过一遍就能覆盖。
- 项目问题带银行特色：问 Agent 历史记忆而不是通用八股。简历上写大模型项目的，要准备"记忆怎么存、怎么检索、上下文多长怎么办"这类工程细节。
- "怎么看城商行的局限性"是综合面高频价值观题，建议从"稳扎稳打、业务理解深、转型同样能做深技术"的角度组织回答，避免抱怨或空谈。
- 从面试到 offer 约两个月，中间有较长的背调和等待期，见[银行与国企科技岗求职指南](../求职规划/银行与国企科技岗求职指南.md)。
