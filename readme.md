## 🧱 项目实战

> 求职最缺的不是「学过技术」，而是「有一个能讲清楚、经得住追问、能写进简历的项目」。

<p align="center">
  <img src="./docs/images/readme-projects.png" alt="项目实战专题：RAG、Agent、AI 评测、结构化抽取、文档解析五个项目" width="100%" />
</p>

十篇拆解都按「先算账、再设计、再验证」组织：动手前先算容量和延迟预算，讲方案必须给替代选项，最后给出能自己跑的验证方法。每篇配数据图和结构示意图，共 27 张数据图与 9 张示意图。

| 项目 | 你在面试里能讲什么 |
| --- | --- |
| [RAG 项目从 0 到 1](./docs/项目实战/RAG项目从0到1.md) | 2.3 秒延迟预算怎么拆、切分策略怎么选、权限条件下推 |
| [Agent 工具调用平台](./docs/项目实战/Agent工具调用平台拆解.md) | 20 轮上下文为什么超窗口、工具怎么设计、权限怎么分级 |
| [AI 应用评测平台](./docs/项目实战/AI应用评测平台拆解.md) | 一次回归为什么近一小时、裁判一致率怎么校准、badcase 怎么回流 |
| [结构化信息抽取系统](./docs/项目实战/结构化信息抽取系统拆解.md) | 阈值 0.76 到 0.90 怎么定、漏错长什么样、字段级置信度 |
| [文档智能解析系统](./docs/项目实战/文档智能解析系统拆解.md) | 一页 6.6 秒花在哪、双栏怎么还原、表格结构怎么给下游 |
| 传统后端副线 | [秒杀、短链、IM、网关、权限](./docs/项目实战/传统后端项目/README.md)五篇，同样按算账、设计、验证写 |

先看[AI 应用研发作品集项目清单](./docs/项目实战/AI应用研发作品集项目清单.md)和[Java 后端校招项目清单](./docs/项目实战/Java后端校招项目清单.md)再选方向。

## 🤖 AI 与大模型

三条不同的路，别混着看：

- **用 AI 提效求职**：[用 AI 求职全流程](./docs/用AI求职全流程.md)是总纲，七个环节各带 AI 工作流、可复制提示词和人工校验点。想先上手看[如何使用大模型提升学习和求职效率](./docs/如何使用大模型提升学习和求职效率.md)。
- **转 AI 应用研发岗**：[岗位能力地图与十二周路线](./docs/AI应用研发/01-岗位能力地图与十二周路线.md)从岗位描述反推学习顺序，配套[专题十篇](./docs/AI应用研发/README.md)。
- **看市场数据**：[AI 岗位数据图谱](./docs/AI求职/02-AI岗位数据图谱.md)与[AI 岗位全景与转型路径](./docs/AI求职/01-AI岗位全景与转型路径.md)。

大模型使用专题另有[十一篇实战文章](./docs/大模型使用/README.md)，覆盖提示词、复习计划、模拟面试、简历打磨、项目复盘和隐私边界。
